🔧 INSTALLATION STEPS
═══════════════════════════════════════════════════════════════════════

1. DOWNLOAD
   - Click the link above or run: download_tesseract.bat
   - Save the installer to your Downloads folder

2. RUN INSTALLER
   - Double-click: tesseract-ocr-w64-setup-5.5.0.20241111.exe
   - Click "Yes" when Windows asks for permission

3. CHOOSE INSTALL LOCATION
   ⚠️ IMPORTANT: Use default path:
   
   C:\Program Files\Tesseract-OCR
   
   ❌ DO NOT install to a different location unless necessary
   ❌ DO NOT install in an existing folder with other files

4. SELECT COMPONENTS
   ✅ Tesseract OCR Engine (required)
   ✅ English language data (required)
   ☐ Additional languages (optional)

5. COMPLETE INSTALLATION
   - Click "Install"
   - Wait for completion
   - Click "Finish"

6. VERIFY INSTALLATION
   Open Command Prompt and run:
   
   tesseract --version
   
   You should see:
   tesseract 5.5.0
   leptonica-1.84.1
   ...

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "tesseract is not recognized"
Solution:
  1. Verify installation folder exists
  2. Add to PATH: C:\Program Files\Tesseract-OCR
  3. Restart Command Prompt/PowerShell

Problem: "Failed to load language data"
Solution:
  1. Check folder: C:\Program Files\Tesseract-OCR\tessdata
  2. Verify eng.traineddata exists
  3. Reinstall if missing

Problem: OCR returns empty text
Solution:
  1. Use clear, high-quality images
  2. Ensure good lighting
  3. Try PNG format
  4. Check image is not blurry
